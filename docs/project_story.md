# 项目讲解

项目从真实工程任务出发：使用 UCI Wine 实测数据，把既有分类服务升级为随机森林。默认实战的修改来自 DeepSeek 响应，独立验收决定是否交付。

按 [真实运行记录](live_practice.md) 讲解这次实战：数据准备 178 条 → 四组实际诊断 → 模型抽取四个 Case → 12 个 Chunk → BGE-M3 / BM25 / RRF → 模型生成代码 → 实际写入 → 五类业务验收与文件完整性检查 → 交付 Patch。本次第一轮通过；没有触发重试或回滚。

通用架构和业务边界见 [架构](architecture.md)。不能从单次成功推导任务成功率或 RAG 增益；旧 ranking 脚本仅用于检查控制分支。
