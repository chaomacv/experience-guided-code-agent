# 项目展示页

无构建依赖的静态页面，依次包含：Agent 架构与 12 项能力映射、实施流程与验证/重试/回滚分支、执行回放、30 条查询的四组检索结果、跨系统下载复现路线。

```bash
# 在项目根目录生成页面中的源码下载文件
python scripts/package_showcase.py
python -m http.server 8080 --directory showcase
```

访问 http://localhost:8080/。需要通过 HTTP 服务读取 data.json 与 guide-data.json，直接双击 index.html
时浏览器通常会阻止读取本地 JSON。部署到支持静态托管的平台即可使用。

- guide-data.json：架构职责、模块映射、实施细节与对应源码。
- guide.js / guide.css：交互说明、状态筛选、复现命令切换与响应式布局。
- i18n.js / locales/en.json / locales/guide.en.json：导航栏中英文切换、界面词条与英文架构/流程说明。默认中文，语言选择保存在浏览器本地，刷新后继续使用；切换时保留当前交互选择。
- data.json：固定的 BGE-M3 实验结果与两条实际执行的脚本 Planner 演示。
- evaluation.json：完整检索实验元数据、分通道证据与限制。
- demo-repair.html / demo-rollback.html：独立 HTML 运行记录。
- experience-guided-code-agent-source.zip：运行打包脚本后生成，已忽略，不纳入 Git。

展示页没有连接服务器或模型 API，不收集访问者数据，也不含密钥。
“回放”与“实时推理”有明确区分。脚本 Planner 预设两轮修改；实际文件动作与测试结果用于展示工作流机制。
英文界面提供案例摘要，原始案例摘录可展开核对。源码、计划 JSON、测试日志与独立 HTML 运行记录保持原文。

Agent 思想对照与实现范围见 [架构映射文档](../docs/agent_module_mapping.md)。页面中的 RAG、ReAct、Reflexion 参考不表示完整论文复现。
## GitHub Pages

正式地址：https://chaomacv.github.io/experience-guided-code-agent/

仓库 Settings → Pages → Build and deployment → Source 选择 GitHub Actions。
`.github/workflows/pages.yml` 在 main 更新后自动生成源码下载包，并发布 showcase 目录。
如首次启用时工作流已经运行失败，在 Actions 中重新运行 Deploy showcase to GitHub Pages。

静态资源和数据使用相对路径，适配仓库子路径；GitHub Pages 无需服务器或 API Key。

## 视觉设计

采用浅色背景、蓝紫重点色、清晰的章节容器与浅色工作流画布。参考 [Teamily](https://teamily.ai/) 的留白和产品展示层次、[Kiro](https://kiro.dev/) 的开发者工具表达与紫色点缀、[Dify](https://dify.ai/zh) 的蓝色节点画布；图形与 UI 为本项目独立实现，未使用参考站点的品牌素材或产品截图。

`studio.css` 统一当前视觉变量与各模块外观，`theme.css` 保留基础布局。首屏 Agent Workspace 为自动播放的架构示意，不是在线执行控制台；具体证据来自下方运行回放。

默认复现已切换为真实 Wine / DeepSeek / BGE-M3 实战。wine-live-report.html 来源于 docs/evidence/wine-live-run.json；旧脚本分支回放折叠归档，仅用于机制回归。
## Hero 知识流水线

使用浅色画布、紫色模型节点、紧凑上下文面板与横向连续镜头。技术名称作为标题和关键词，中文解释内容与因果；英文模式同步切换说明。聊天、Case、Chunk、索引与上下文都是可编辑的 HTML，不是静态图片。

首屏使用人工编写的 loss 替换对话：短用户消息、较长助手回复、代码块与消息间留白；聊天气泡参考常见即时通信布局。LLM 节点只展示“理解语义 → 结构化抽取”。LLM 后不再单列 EngineeringCase 详情卡；task、constraint、solution 先合为一张知识卡，进入向量化时由同一组 HTML 元素拆成三张 Chunk。字段标题使用 13px，摘要正文使用 10px。聊天人物在左、机器人在右，气泡尾角与角色位置一致。

| 时间 | 叙事 |
| --- | --- |
| 0–3 秒 | 历史对话进入工作区 |
| 3–11 秒 | 对话抽取成整张知识卡，然后展开 |
| 11–18 秒 | 分块编码、入库；镜头停留 3 秒 |
| 18–28 秒 | 新任务下滑进入；检索场景停留 4.5 秒，步骤与结果依次高亮 |
| 28–34 秒 | 多源信息汇聚，镜头停留 3 秒 |
| 34–38 秒 | 交给模型推进；遮罩覆盖循环复位 |

Knowledge Index 使用经验条目与中文说明解释语义、关键词查找；统一检索卡片概括当前 Dense + BM25 + RRF 的职责，没有改动实际检索算法。首屏 loss 对话是架构说明，不是已执行的训练日志；下方 WineService 仍是当前可复现业务实战。

当前代码使用文本 LLM，修改文件与独立验收由工具执行。MLLM 在交接节点明确标为可扩展方向，不表示已经接入多模态模型，也不表示模型直接写入文件或访问受保护验收标签。

实现文件：`index.html` 的 `#knowledge-story`、`knowledge-story.css`、`knowledge-story.js` 与 `locales/en.json`。所有动画共用原生 Web Animations API 的 38 秒时间轴；无外部 CDN 或新增构建依赖。保留自动播放、暂停、重播、阶段跳转、后台和离屏暂停；窄屏简化分镜，减少动态效果时手动阅读。

本地预览：仓库根目录运行 `python -m http.server 8765 --bind 127.0.0.1 --directory showcase`，打开 `http://127.0.0.1:8765/`。发布沿用 GitHub Pages，源码下载包由 `scripts/package_showcase.py` 生成。

镜头节奏：保留起点与抽取，在同一横向画布中经过拆分、编码、入库、检索、汇聚与行动。各段平滑移动，在阶段到达时短暂停留；卡片预先位于轨道中，信息转换和汇入在同一空间发生。

动画检查修正：检索结果与增强任务内容预先完整显示，过程只用轻微高亮和信息流表示，不再让空卡片进入视口。鼠标悬停自动暂停，移开后从原处继续；手动暂停优先，不会因移开鼠标而恢复。打包会为样式、脚本和语言包生成内容版本号，避免连续发布后混用新旧资源。

知识卡边展开边前移；Embedding 与 Index 预先位于轨道中，以“文本标签 → 向量条带 → 入库”的同一载体动画建立空间衔接。

卡片标题统一使用 Knowledge Index 的两行格式：14px 加粗英文名称、11px 中文职责说明，统一字体、行高与间距。历史对话、结构化知识、编码、索引、检索、上下文来源与增强任务使用共享样式；拆分说明下方不再使用独立箭头，连接线随知识卡移动延伸。

镜头在入库、检索、汇聚节点分别停留 3、4.5、3 秒，开场与抽取沿用原有阅读停留，行动节点保留结尾停留；各段用缓入缓出连接，暂停时信息流仍继续，不切换页面。

宽屏 Agent Workspace 最大宽度为 1500px（原 1200px），画布内容随可用宽度等比例缩放；移动端保留原有分镜布局。


检索阶段的新任务卡片缩短并使用通用说明，12.5–13.5 秒从上方滑入；底部知识库来源标签与沿线流动点说明经验如何进入检索。

## 浅色视觉与交互

`studio.css` 是当前页面的完整视觉层；`studio.js` 负责首次滚动的渐进显示和章节光晕的视口播放控制，不改变复现数据或原有交互功能。各主要章节使用独立边界、编号与留白；下载区保留所有原有文字、路线、命令、下载链接与报告入口。

聊天采用纯色底和蓝白气泡，用户左侧、助手右侧，保留角色文字与时间，移除头像。增强任务卡片压缩高度；新任务说明与经验说明同为 10px。检索步骤与相关经验使用边缘光、底色及持续高亮，而非细边框一闪而过。

动画使用 24 个叙事时间单位映射到 38 秒实际播放时间，阶段按钮、进度、悬停/手动暂停、后台与离屏暂停共用同一个时钟。首次滚动显示只隐藏初始屏幕下方的待显示元素；直接打开锚点和减少动态效果模式时内容始终可见。

整体回到浅色阅读背景，保留章节边界、滚动显现、38 秒时间轴、悬停暂停、明显高亮、紧凑增强任务及蓝白聊天气泡。

章节按浅蓝、浅紫、薄荷、杏色、雾蓝、浅粉区分，使用纯色渐变与 28 秒慢速光晕；光晕只在章节靠近视口时播放，减少动态效果模式中保持静态。四路上下文汇入采用连续三次贝塞尔曲线，避免曲线后突然折角。

聊天卡片去掉底部说明栏，背景延伸至卡片底部；用户气泡为浅蓝，助手回复采用统一白底，代码保持等宽排版且不再单独使用黑色底。

检索光效按顺序播放：先完成 Retrieve → Match → Rank → Select，再依次高亮三条历史经验，两组动画不重叠，仍处于同一段 4.5 秒镜头停留内。首页移除独立的真实模型实操展示区及对应导航，报告与证据文件继续保留。


## 按 Agent 能力探索扩展

02 章节中的实现表可点击第一列模块名，在同一区域切换到扩展资源。表中实现与状态仍来自 guide-data；资源单独维护，不代表本项目已经集成了这些工具。

- `explore-data.json`：12 项能力的双语介绍、项目切入点和资源链接。LLM 按 API、开放权重模型、部署工具分组；其余能力每项精选 4 个资源。
- `explore.js` / `explore.css`：资源导航、返回清单、浏览器前后退、深链接及小屏幕布局。中英文切换保留当前模块，返回清单保留状态筛选。
- 可分享 `#explore-llm`、`#explore-prompt`、`#explore-rag` 等链接；默认入口仍为实现清单。

资源更新后运行 `python scripts/package_showcase.py`，会同步资源数据与脚本版本并重建源码下载包。维护时优先保留官方文档或官方仓库链接，避免在页面固定具体模型版本、价格或 Star 排名。
